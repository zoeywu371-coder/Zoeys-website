# Zoey's Personal Website!

A clean, simple, and responsive personal webpage built from scratch using HTML5. Created as a foundational web development project to organize my developer links, projects, and bio.

## Features
* **Responsive Design:** Made for easy viewing across both desktop and mobile devices.
* **Quick Access Links:** Direct links to my GitHub and contacts.
* **Personal Bio:** Get to know who Zoey is!

## Technologies Used
* HTML
* VS Code
